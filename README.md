# Maharani Cafe - Digital QR Menu

A mobile-friendly digital menu and order portal for Maharani Cafe, Jaipur.

## What is inside

- Pure vegetarian menu across 10 categories (Fries, Momos, Pizza, Panini, Burgers, etc.)
- Quick category navigation and search
- Cart cloche with table selection and takeaway options
- Direct WhatsApp order confirmation

## Setup

Open `index.html` in any browser or deploy directly to Netlify or Vercel.
